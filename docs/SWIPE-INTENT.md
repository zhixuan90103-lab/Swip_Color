# 滑动意图 — 设计（真机连甩）

日期：**2026-09-10**。玩法门槛数字仍以 [ICE-PUZZLE.md](./ICE-PUZZLE.md) §4 / `FEEL2_DEFAULT` 为准。本文管 **怎么认手势**，不管 ①②。

真机问题：每次抬手再上下甩，仍会把上认成下（或反过来）。补丁（速度同号、回抽锁、80ms 窗）治不好，因为模型把 **两划的触摸事件揉在一起**。

---

## 问题

连甩 = 很多个 **短生命周期手势**，不是一根手指的连续轨迹。

手机上常见：

1. 上一划的 `pointerup` 迟到，且 `pointerId` 复用 → 被当成这一划的抬手，用上一划结束点减这一划起点 → **必然 180° 反号**。  
2. 按下瞬间带着上一划的回弹/接触抖动，若把抖动算进方向，第一下会反。  
3. 速度窗跨手势或二次拟合会出 **与手指相反的速度**（Chromium / Android VelocityTracker）。方向若信速度，就会反。

## 模型

一次按下 = 一个手势，状态互不借用。

```
Idle → Down（死区内）→ Armed（出死区，原点改到这里）→ Fired 或 Ended
```

| 规则 | 做法 |
|------|------|
| 隔离 | 只认当前 `pointerId` + `timeStamp ≥ 本次 down`。别的指针、过期 up/move **丢掉**，绝不 `grab` 偷接 |
| 原点 | **按下点**。死区只决定何时开始认方向，出手距离从按下点沿锁轴量（对齐 2048 手感 2） |
| 方向 | **只看按下点到现在的位移符号**。速度 **只当够不够快**，正负绝不改方向 |
| 出手 | 主轴够 `commit`、轴比够、速度够 → move 上出手。一次手势只一步 |
| 滑棋忙 | 记下下一步，格点滑完再走 |
| 转场忙 | 星星遮罩期间 **不排队**。开始/结束都丢掉已存输入，避免看不见的第一次 + 第二次连打两步 |
| 斜滑 | 太斜则等甩直。出手看 **当前主位移**，不沿早先锁死的轴。冰面 **不做**「哪向能走就改判哪向」（那会把朝墙的一滑拐成横飞） |
| 失败 | 出了死区但没出手就抬手：短滑回声。点按无回声 |
| 一次一势 | 手势没抬手，忽略新的 pointerdown（防止一划里二次按下） |
| 轻重 | 压感明显偏轻则加高距离/速度门槛。出手后 10ms 内新按下当弹跳忽略。 |

明确不做：用速度符号当方向、用上一划速度、二次拟合、同按住连走、识别器看箱子。

## 验收

真机：抬手连甩 上-下-上-下 至少 8 次，每下方向与手指一致。人还在滑时甩反方向，滑完应走反方向那一步，不是重复上一步。
