# 滑动意图

日期：**2026-09-10**。门槛数字以 [ICE-PUZZLE.md](./ICE-PUZZLE.md) §4 / `FEEL2_DEFAULT` 为准。①② 不在识别层。

一次按下 = 一个四向命令。滑动中够门槛就出手（对齐 2048 手感 2）。

```
Idle → Down（死区内）→ Armed → Fired | Ended
```

## 判定（必须同时过）

| | 默认 | 怎么量 |
|---|---|---|
| 死区 `slopPx` | 10 | 小于此不当滑。过了才开始认方向 |
| 出手 `commitPx` | 30 | **从按下点**沿当前主轴的位移，不是过死区再加一段 |
| 速度 `speedPxS` | 200 | 本手势约 80ms 窗、沿 **当前更长那根轴** 的速度。只当够不够快，**正负不改方向** |
| 轴比 `axisRatio` | 1.55 | 主轴 ≥ 副轴 × 1.55 才认方向；太斜等甩直 |

方向 = 按下点到现在，更长那根轴的符号。不沿「早先锁死」的轴出手（先横后竖会走竖）。  
冰面 **不** 按「哪向能走」改判（朝墙就砸，不拐成横飞）。

上一手已经出手、这一手主轴与它 **相反**：出手距离用 `commitPx × 0.4`（不低于死区）。右甩完立刻小幅向左，按向左认，不会仍按「离按下点还偏右」或满 30px 才认。同向仍要满 30px。

## 手势隔离

- 只认当前 `pointerId`，且 `timeStamp ≥ 本次 down`。过期 up/move 丢掉。  
- 这一手 **还没出手**：不接新的 pointerdown（防一次当两次）。  
- 这一手 **已经出手**，且超过约 16ms 没有新点：允许新的按下顶替（抬手事件晚到时才能开反向）。过期的那次 up 因时间戳早于新 down 被丢掉。  
- letterbox 外、顶/底安全区起手：整次不走棋。  
- 出手后 **10ms** 内新按下当弹跳丢掉。

## 忙

| | |
|---|---|
| 格点还在滑 | 可预存 **一步**，后一次覆盖前一次，滑完再走 |
| 星星转场 | **不预存**。开始/换关/结束都 `cancelInput`，避免看不见的第一次 + 补滑打出两步 |

## 不做

抬手才判向、速度符号当方向、识别器看箱子、同按住连走、出死区后再等 40ms/3 点、合法向分叉。

## 验收

真机连甩上-下-上-下方向跟手指；斜着朝墙砸一下不横飞；转场遮罩时甩、干净后再甩只走一步。
