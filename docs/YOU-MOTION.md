# 角色与场面 juice

日期：**2026-09-09**。本文是**运动 / juice 真源**。  
玩法以 [ICE-PUZZLE.md](./ICE-PUZZLE.md) 为准。贴图 / 层级以 [VISUAL.md](./VISUAL.md) 为准。  
Juice **不改模拟**：格点先到位，再播表现。`prefers-reduced-motion: reduce` 时停动画。

**操作反馈第一优先：** 仅角色/箱子**格点在滑**时锁输入。撞停 juice、脚下光、飞星、待机期间，下一手必须立刻能出；新滑步打断未播完的砸入/回弹。

## 1. 角色轴

| 层 | 节点 | 做什么 |
|----|------|--------|
| 格点 | `#ice-you` `left/top` | 空滑 **50ms/格**；推箱 **90ms/格**，linear |
| 冲撞 | `--you-hit-x/y` | 叠入 / 回弹，不改格点 |
| 投影 | `.ground-blob.is-you-blob` | 脚底接触椭圆（随人走，不复制身体图） |
| 身体 | `.you-rig` | 左右脚底 `50% 100%`；上下砸入 Y 缩放改 **中心**。**无 filter** |
| 眼 | `.you-eye` / `.you-pupil` | 睑 `scaleY`；瞳孔 `translate` |

禁止绕肚子转、禁止整图抖动当摆正。  
不要把 `body.png` 再铺一层当投影：静止剪影 + 晃动身体 = 两个角色。接地：圆用椭圆、方用圆角方板；**禁止** `filter: drop-shadow`。星只用泛光。

## 2. 待机

四拍：**左拉伸 → 中间蹲持 → 右拉伸 → 中间蹲持**。  
半周：0–0.16 持 → 0.16–0.50 到侧 → 0.50–0.54 侧持 → 0.54–0.88 回家 → 0.88–1 持。

倾 0.5–1°，中压 0.09–0.15，侧拉 0.20–0.30，周期 1.55–1.95s。幅度周期结束 **lerp**。`sx×sy≈1`。脚钉住，无 `translateY`。滑行 / 冲撞时暂停待机。

---

## 3. 滑行

与待机分开。出手仍是手感 2。

- 空滑 **50ms/格**（`FEEL2_DEFAULT.slideMs`）
- 推箱 `kind=push` 人箱同行 **90ms/格**（`PUSH_STEP_MS`）
- 左右倾 14° + 拉长 0.22；上下不倾只拉长
- 眼 160ms：先收到 0.72，再看滑动方向
- 逻辑滑步结束即解锁输入，不必等砸入播完

原地给方向但格点不动：无逻辑位移，砸入不锁手，幅度按 0 格。

---

## 4. 冲撞 → 回弹 → 摆正

**不是玩法位移。** 人已停在撞停格。

| 段 | 满幅 / 小幅 | 内容 |
|----|-------------|------|
| 砸入 | 55ms / 70ms | 叠进障碍，ease-out cubic |
| 回弹 | 255ms / 300ms | 反方向弹、绕脚衰减摆正 |

- 砸入 26px；overlap 18px；负半周 × 2.6
- 左右倾满幅 22°（从滑行 14° 接着砸，不先清零）
- 上下：整身走 `--you-hit-y`；Y 压扁绕中心；X 按体积约 72% 拉宽
- 左右压扁 0.34、回弹拉长 0.28；垂直轴只微鼓

**幅度按走过格数**（空滑与推箱同一套；表中数字 = 满幅的比例）：

| 格数 | 幅度 |
|------|------|
| 0（原地顶） | 45% |
| 1 | 45% |
| 2 / 3 / 4+ | ≈63% / 82% / 100% |

幅度越大越快。结束把姿态交给待机弹簧（中间蹲持起），禁止跳帧。

**眼睛：** 滑 / 砸 / 弹看滑动方向；进待机半眨眼（闭到 50%）收回前方；之后正常眨眼闭到 70%。

## 5. 箱子

死物，无待机。人停在箱前（刹车 / 原地顶 / 推到头）与角色砸入同一帧。

- 硬木箱：压扁 0.05；沿力 **4px** 快收；抬 **4px** 再沉
- 绕**中心**整段指数衰减晃（约 2 圈）；左右峰值约 **7°**、上下约 **4°**
- 幅度跟 `hitAmpForCells`（按格数）
- 每次略随机；约 18% 更闷
- `--box-hit-x/y` + `.box-rig`

石头 / 外框撞不动，**不喷粒子**。

## 6. 接地：脚影 + 格子提亮

两套各干一件事，**不准再用 mix-blend**（iOS 会印成深色方块），**不准再用 `filter: drop-shadow`**（合成层横切黑带 / 裁影）。

| 层 | 节点 | 做什么 |
|----|------|--------|
| 接地 | `.ground-blob` | 人 `you/shadow.png`；石头 `wall-shadow.png`；箱 `crate-shadow.png`。星无此层 |
| 占用提亮 | `.ice-cell-add` | 贴图与该格 `ice-a` / `ice-b` 相同。角色所在格立刻 `0.5`（不淡入，否则 50ms/格来不及），离开后按步时淡出到 0 |

进入新格不要瞬间打满再切 transition——淡入淡出同一条 opacity。禁止 `plus-lighter` / `multiply`。冰格 `overflow: visible`，提亮不要被格边切成方块。删掉其中一层都不算修好。

## 7. 星与 HUD

| 状态 | 位置 / 动作 |
|------|-------------|
| 关卡收集星（未吃） | 钉在自己格；待机只在格内上下浮（只泛光，不要投影） |
| 终点装饰星 | 门格再叠一颗同结构的星；待机同样浮；**不是收集物** |
| 吃到收集星 | 滑到该格**当下**起飞：自身格正上浮 **100px**（高度度量，不飞角色头）→ 蹲 50px → 飞 HUD 槽 0 / 1 |
| 滑到门格 | **当下**终点星同样起飞 → HUD 槽 2 |
| 结算 | 等**全部飞星结束** + HUD 弹出（约 280ms）再出 overlay |

HUD 三槽。评价公式仍是规则里的 **1 + 吃到的星**，见 ICE-PUZZLE。
