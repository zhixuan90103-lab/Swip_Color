# 角色运动

日期：**2026-09-09**。本文是**角色 juice 真源**（待机、滑行、冲撞、回弹、摆正、眼睛）。  
玩法规则仍以 [ICE-PUZZLE.md](./ICE-PUZZLE.md) 为准。贴图对位以 [VISUAL.md](./VISUAL.md) 为准。  
实现：`src/game/youMotion.ts`。`iceGame.ts` 只负责何时开滑、何时撞停。

Juice **不改模拟**：格点在最后一格已经停住；冲撞/回弹只是 `--you-hit-x/y` 与 `.you-rig` 的旋转缩放。

`prefers-reduced-motion: reduce` 时整套停。

---

## 1. 轴与层

| 层 | 节点 | 做什么 |
|----|------|--------|
| 格点 | `#ice-you` 的 `left/top` | 每格位移，**50ms** linear（与 `FEEL2_DEFAULT.slideMs` 对齐） |
| 冲撞位移 | `#ice-you` 的 `--you-hit-x/y` | 叠入 / 回弹，不改格点 |
| 身体 | `.you-rig` | `transform-origin: 50% 100%`（**脚底**）。旋转 + 缩放 |
| 眼皮 | `.you-eye` | `scaleY` 眨眼 |
| 瞳孔 | `.you-pupil` | `translate` 看向 |

禁止绕肚子转、禁止整图位置抖动当摆正。

## 2. 待机（四拍呼吸）

锁定节奏：**左拉伸 → 中间蹲持 → 右拉伸 → 中间蹲持**。

半周（0–1 的一半）：

| 段 | 相位 | 动作 |
|----|------|------|
| 0–0.16 | 中间持 | 倾角 0 |
| 0.16–0.50 | ease-in-out 到侧 | 倾到该侧 |
| 0.50–0.54 | 侧持 | |
| 0.54–0.88 | ease-in-out 回家 | |
| 0.88–1.0 | 中间持 | |

- 倾角 **0.5–1°**
- 中间压扁 **0.09–0.15**
- 侧向拉长 **0.20–0.30**
- 周期 **1.55–1.95s**
- 幅度周期结束时 lerp，禁止跳变
- 体积守恒：`sx × sy ≈ 1`
- 脚钉在 rig 底，**不要** `translateY` 呼吸
- 滑行或冲撞时暂停待机，身体弹簧收到直立

## 3. 滑行

与待机分开。出手仍是手感 2。空滑 **每格 50ms**；**推箱每格 90ms**（人箱同行）。总时长 = 格数 × 该档。

- 左右：倾 **14°**（右正），沿滑动方向拉长 **0.22**，不另做压扁脉冲
- 上下：不倾，只拉长
- 眼睛：前 40% 眼皮收到 0.72，再看向滑动方向，然后睁开（总 **160ms**）。不是待机全闭眨眼
- 双闪只算一次换看向；空眨眼不换看向

---

## 4. 冲撞 → 回弹 → 摆正

**回弹不是玩法位移。** 人已经停在撞停格。

### 4.1 两截

| 段 | 时长 | 是什么 |
|----|------|--------|
| 砸入 | 满幅 **55ms** / 原地 **70ms**，ease-out cubic | 沿滑动方向叠进墙/石/箱，脚为轴继续前倾 |
| 回弹 | 满幅 **255ms** / 原地 **300ms** | 从最深点沿**反方向**弹回、过格心、绕脚衰减摆正 |

回弹包络（`u = 0…1` 为回弹进度）：

- 位移：`exp(-3.1 u) * cos(2.15π u)`；负半周距离 = overlap × 2.6
- 绕脚摆：`exp(-2.4 u) * cos(2π u)` 叠在倾角上
- 砸入距离满幅 **26px**；overlap **18px**
- 左右砸入倾角满幅 **22°**（从滑行 14° 接着砸，不先清零）；绕脚摆正
- **上下**不绕脚倾。整身位移仍走 `--you-hit-y`；Y 压扁/拉长绕**身体中心**（`50% 50%`），不要绕脚底（否则头被钉住、回弹看不见下沉）。Y 压扁时 X 按体积约 **72%** 拉宽（不是 `1/sy` 全量，避免过宽）
- 左右砸入压扁 **0.34**；回弹拉长 **0.28**；左右垂直轴只微鼓，**不要** `1/axis` 拉得过高

### 4.2 幅度

现行砸入/回弹/摆正数字 = **满幅度**。

| 情况 | 幅度 |
|------|------|
| 原地顶死（0 格） | **45%** |
| 空滑或推箱 1 格 | **45%** |
| 2 / 3 / 4+ 格 | 约 63% / 82% / **100%** |

满幅更快：砸入 55ms、回弹 255ms。1 格 / 原地 45% 仍是 70ms + 300ms。幅度越大越快，曲线形状不变。空滑与推箱都按格数衰减。

### 4.3 接到待机

包络结束时不要把姿态清零。把当前倾角/缩放交给待机弹簧；待机从四拍**中间蹲持**起。残余位移继续阻尼回格心。禁止跳一帧。

## 5. 眼睛

| 阶段 | 看向 |
|------|------|
| 滑行、砸入、回弹 | 一直看**滑动方向**（瞳孔约 7px） |
| 回弹 | 看向之上可叠一点点主轴/垂直轴晃，衰减到 0 |
| 进待机 | **半闭眨眼（闭到 50%）**，瞳孔收回目视前方 |
| 之后 | 正常眨眼逻辑 |

正常眨眼：闭到 **70%**（还留 30% 开），时长 180ms。看向只在一次眨眼序列开始时换（双闪 = 一次换看向）。默认目视前方；偶尔看星/门。

## 7. 箱子

死物，**没有待机**。只在被角色撞到时给受力反馈（juice，不改格点）。实现：`src/game/boxMotion.ts`。

撞箱时机：人停在箱前（刹车 / 原地顶 / 推到头）。与角色砸入同一帧起。

- **硬材质**：几乎不弹、不挤扁（压扁仅 **0.05**）
- 被撞开：沿受力方向挪 **4px**，很快收回；抬起 **4px** 再沉下去
- 绕**中心**晃：撞击起就左右摆，整段指数衰减到 0（约 2 圈）；左右峰值约 **7°**，上下约 **4°**
- 回正满幅 **200ms** / 原地 **240ms**
- 幅度与人相同：滑行满幅，原地 45%
- 每次撞击在位移/抬起/转角/衰减上略随机，避免同一套动作；约 18% 更沉的闷撞（更小抬起）
- 位移走 `--box-hit-x/y`，旋转缩放走 `.box-rig`
