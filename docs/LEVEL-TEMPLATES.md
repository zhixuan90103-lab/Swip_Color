# 十五关（现行）

日期：**2026-09-07**。玩法真源：[ICE-PUZZLE.md](./ICE-PUZZLE.md)。  
实现：`src/game/levels.ts`。单测：`src/game/iceSim.test.ts`（每关 1/2/3 星都有路；3 星必须 ①/②；满星不回起点；十五关满星解法互不相同）。

记号：你 / 箱 / 星 / 门 / 空 / 墙。未写墙的格都是冰。

---

## 曲线

| 关 | 一句话 | 骨架 |
|----|--------|------|
| 1 | 撞停对齐底中门 | ① 教学 |
| 2 | 贴着推到头，再绕星 | ② 教学 |
| 3 | 右推到 B，绕北再下推到 C | 推到再推 |
| 4 | 中间箱先别推，多面撞停 | 枢纽钉（原 6） |
| 5 | 先 ① 停住，走开，再 ② 同一只 | 先停后推 |
| 6 | 枢纽用完再把钉推走 | 用完再走（原 10） |
| 7 | 先当刹车，再推到门列 | 停完再搬 |
| 8 | 钉子不在正中 | 偏心钉 |
| 9 | 从下往上推到再推，门在顶 | 推到再推·反向 |
| 10 | 先停后推，门偏右 | 先停后推·偏门 |
| 11 | 人在顶上，往下撞枢纽 | 枢纽·从上 |
| 12 | 多一只箱挡着角，中间仍是枢纽 | 枢纽·闲箱 |
| 13 | 偏心钉 + 顶上一只闲箱 | 偏心·变种 |
| 14 | 先停后推，顶上多一只箱 | 先停后推·三箱 |
| 15 | 枢纽、推走、再停，三步进门 | 收束 |

每关另有 **2 星** 最短路（只吃一颗再进门），见单测 BFS。满星最短路见 `iceSim.test.ts` 的 `THREE`。

---

## 盘面要点

第 **4、6** 关是枢纽骨架（玩家点名有意思的那两套）。后面关是变种：换出发边、换门、加闲箱、加墙挡捷径，**不是转 90° 克隆**。

第 1 关只教 ①；第 2 关第一下就是 ②。
