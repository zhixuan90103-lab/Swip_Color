# 冰面推箱 — 玩法规范

日期：**2026-09-07**。本文是规则真源。代码与本文冲突时改其中一侧。

实现：`src/game/iceSim.ts`（一滑）· `iceGame.ts`（画面、十关连续）· `levels.ts`（十关）· `swipeInput.ts` + `FEEL2_DEFAULT`（出手）。  
出题知识：[LEVEL-KNOWLEDGE.md](./LEVEL-KNOWLEDGE.md)。现行十关：[LEVEL-TEMPLATES.md](./LEVEL-TEMPLATES.md)。

---

## 1. 一句话

一人在矩形冰面上滑。箱子是**可搬的停车点**：先当刹车，贴着再推则人箱同行直到卡住。用停车点把路线拐到星星上，最后进门。

听令的只有人。不合成、不新出块、不指挥全盘。

---

## 2. 必须先对齐的共识

**格子多，不等于满星容易。箱子是管路径的，不是推到边上就算完。**

- 矩形范围内 **默认全是冰格**：要画、能走。没有墙砖的位置仍是格子，不要挖空，也不要用墙去填满矩形。
- 玩家可以滑进「设计路线之外」的格。这只增加自由度。
- **三星只认设计路线。** 不按设计路走，进门只有 1 星。多出来的冰给不了星星。
- 内部 **墙砖非必要不放**。只有必须挡住一条**绕星捷径**时才放（通常是星两侧各一块，防止从旁边擦进）。不是「一点墙都不能有」，也不是整列砌口袋。
- 外框画在格子 **外面**，不和格子重叠。

---

## 3. 格子

| 格子 | 含义 |
|------|------|
| 空 | 冰。一滑从这里飞过 |
| 墙 | 仅必须挡路时才有的内部砖 |
| 你 | 角色，唯一听四向 |
| 箱 | 刹车 / 可推（停车钉） |
| 星 | 人经过即吃（不必停在上面） |
| 门 | 人进入即过关 |

箱可停在冰上，**不能进门格**。星不挡人、不挡箱；箱压在星上但人没走那格则不吃。

停下当且仅当下一格是：外框、内部墙砖、箱子。

---

## 4. 输入（与旧 2048 出手一致）

只认方向，不点选某一块。走棋用 **手感 2 甩动**（`FEEL2_DEFAULT`），不是另写一套薄滑动。

- 死区 `slopPx` 10、出手距离 `commitPx` 30、轴比 `axisRatio` 1.55  
- 80ms 速度窗，`speedPxS` 200；慢了锁死，本按下再加速也不走  
- **每次按下只一步**（贴着推箱要再滑一次）  
- 约 40°–45° 斜滑：未锁轴时只走「唯一能走」的那向  
- 顶/底安全区起手不走棋  
- 一滑的运动结束才接受下一滑  
- 方向键与滑动同一套走棋  

---

## 5. 箱子：刹车与推

看这一滑 **起步时** 面前一格是不是箱子。

| 起步 | 方向 | 结果 |
|------|------|
| 面前是空，滑到半路碰上箱 | 任意 | **① 刹车**：人停、箱不动 |
| 面前是箱 | 朝箱 | **② 推**：人+箱一起滑，直到箱卡住；人停箱后一格 |
| 任意 | 朝没有贴箱的方向 | 只有人滑，箱不动 |
| 面前是箱但箱已卡住 | 朝箱 | 都不动 |

一次只推贴着的那一只。箱顶到另一只箱即停，不连锁撞飞。卡住 = 箱的下一格是外框、墙砖、另一只箱或门。

**出题时箱子的职责：** 让人停在**能拐弯的那一格**。不是把箱子推到地图最右侧就算用过箱子。

---

## 6. 过关与三星

- 人进入门 → 过关，评价 **1 星**（没吃星也可以）。  
- 场上最多两颗星，路径擦过即吃，每颗 **+1**。两颗都吃到再进门 = **3 星**。  
- 缺星不失败。可重开刷三星。十关连续：过关「下一关」，第 10 关「再来一遍」。  
- 星星必须放在：不走设计路线（要用 ① 或 ② 停在路口再转）就擦不到的位置。

---

## 7. 出题铁律

1. 先铺满矩形冰，再放你、箱、星、门。墙砖最后：只挡「不碰箱子也能擦到星」的那条线。  
2. **满星是一条向前的路**：星 → 星 → 门。进门是路线终点，**禁止**「吃光星星 → 原路返回起点 → 再向下进门」。转弯、推箱算前进。  
3. **一星是提前进门**（现行十关：开局向下），不是吃完再折回。左列到门必须畅通，不依赖箱子。  
4. 多出来的冰可以乱走，但不能变成满星捷径。验收：BFS 禁止 ① 和 ② 时，吃不到两颗星（`iceSim.test.ts` 的 `canThreeStarsWithoutBox`）。  
5. 满星路线中途不得回到开局格（`returnsToStartBeforeWin`）。  
6. 教学：第 1 关只教 ①；第 2 关强迫 ②。不要十关同一张「右袋/竖井吃完再折返」。  
7. 一关一句话。说不清这关箱子在管哪一次转弯，就拆掉。

### 已否决的出题（实装翻过车）

| 否决 | 原因 |
|------|------|
| 星放在畅通行列上 | 多走一个往返就能 3 星，箱子摆设 |
| 十关同一口竖袋，推箱到最右再下井折返 | 玩法相同，没有路径管理 |
| 用墙填满矩形 / 挖空当墙 | 多余格应是冰 |
| 第 1 关零墙且星在飞过路径上 | 墙该加在挡捷径处；不是永远零墙 |

## 8. 第 1 关「转弯钉」

3×4。星两侧各一块墙，箱子在右上当停车钉。满星 **右 → 下 → 左** 进门，不回起点。

| | 一 | 二 | 三 | 四 |
|--|--|--|--|--|
| **1** | 你 | 空 | 空 | 箱 |
| **2** | 空 | 墙 | 星 | 墙 |
| **3** | 门 | 星 | 空 | 空 |

**一星** 下（左列直进门）。

**三星** 右（① 停在第 3 列）→ 下（擦上星）→ 左（擦下星并进门）。

其余九关见 [LEVEL-TEMPLATES.md](./LEVEL-TEMPLATES.md)。单测：`src/game/iceSim.test.ts`。
