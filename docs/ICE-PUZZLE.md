## 1. 一句话

一人在矩形冰面上滑。箱子是**可搬的停车点**：先当刹车，贴着再推则人箱同行直到卡住。用停车点把路线拐到星星上，最后进门。

听令的只有人。不合成、不新出块、不指挥全盘。

---

## 2. 必须先对齐的共识

**格子多，不等于满星容易。箱子是管路径的，不是推到边上就算完。**

- 矩形范围内 **默认全是冰格**：要画、能走。没有墙砖的位置仍是格子，不要挖空，也不要用墙去填满矩形。
- 玩家可以滑进「设计路线之外」的格。这只增加自由度。
- **三星只认设计路线。** 不按设计路走，进门只有 1 星。多出来的冰给不了星星。
- 内部 **墙砖非必要不放**。只有必须挡住一条**绕星捷径**时才放（通常是星两侧各一块，防止从旁边擦进）。不是「一点墙都不能有」，也不是整列砌口袋。
- 外框画在格子 **外面**，不和格子重叠（九宫托盘；框距可微调，见 VISUAL）。

---

## 3. 格子

| 格子 | 含义 |
|------|------|
| 空 | 冰。一滑从这里飞过 |
| 墙 | 仅必须挡路时才有的内部砖 |
| 你 | 角色，唯一听四向 |
| 箱 | 刹车 / 可推（停车钉） |
| 星 | 人经过即吃（不必停在上面） |
| 门 | 人进入即过关（冰格仍在；画面是终点垫 + 装饰星，见 VISUAL） |

箱可停在冰上，**不能进门格**。星不挡人、不挡箱；箱压在星上但人没走那格则不吃。

停下当且仅当下一格是：外框、内部墙砖、箱子。

---

## 4. 输入（手感 2 甩动）

只认方向，不点选某一块。走棋用 **手感 2**（`FEEL2_DEFAULT`）。手势模型：[SWIPE-INTENT.md](./SWIPE-INTENT.md)。

- 死区 `slopPx` 10、出手距离 `commitPx` 30、轴比 `axisRatio` 1.55（与 2048 手感 2 相同）  
- 出手速度 `speedPxS` 200；从 **按下点** 沿锁轴量出手距离（死区只决定何时开始认方向，不另加一段）  
- 一次按下只一步；过期触摸丢掉。出手后 10ms 内新按下当弹跳丢掉  
- 格点还在滑：记下这一步，滑完再走  
- 斜滑等甩直；方向以当前主位移为准，不因墙/箱改判到另一向  
- 顶/底安全区起手不走棋；letterbox 外不起手  
- 只在格点逻辑移动期间锁输入  
- 短滑未出手：0 格砸入。已出手顶死：0 格砸入  
- 方向键与滑动走同一套 `applyDir`；键无甩动门槛

## 5. 箱子：刹车与推

看这一滑 **起步时** 面前一格是不是箱子。

| 起步 | 方向 | 结果 |
|------|------|
| 面前是空，滑到半路碰上箱 | 任意 | **① 刹车**：人停、箱不动 |
| 面前是箱 | 朝箱 | **② 推**：人+箱一起滑，直到箱卡住；人停箱后一格 |
| 任意 | 朝没有贴箱的方向 | 只有人滑，箱不动 |
| 面前是箱但箱已卡住 | 朝箱 | 都不动 |

一次只推贴着的那一只。箱顶到另一只箱即停，不连锁撞飞。卡住 = 箱的下一格是外框、墙砖、另一只箱或门。

**出题时箱子的职责：** 让人停在**能拐弯的那一格**。更好的题：
- **推到 B，再推到 C，走腾出来的路回去**
- **同一只钉反复当车站**（从不同方向撞停，先不推走）
- **先 ① 停住 → 去改别的路 → 再回来 ② 用这只箱去下一处**

## 6. 过关与三星

- 人进入门 → 过关。评价 = **1 + 吃到的星**（0 颗 → 1 星，1 颗 → 2 星，2 颗 → 3 星）。  
- 场上收集星两颗。画面 HUD 三槽、飞星与结算时机见 YOU-MOTION，不改本公式。  
- 每关都要有 **三条设计路线**：不吃星进门（1）、只吃一颗（2）、两颗都吃（3）。  
- **门的位置是出题环节**：不必放角落。用墙和箱子规划「怎么停在能进门的那一格」。进门可以依赖 ①②。  
- 缺星不失败。可重开刷更高评价。十五关连续：过关「下一关」，第 15 关「再来一遍」。重开 / 下一关走镂空星转场（YOU-MOTION §8）。  
- 两颗星都要放在：不走满星路线（要用 ① 或 ② 停在路口再转）就齐不了。只吃一颗可以是「半条设计路」。

## 7. 出题铁律

1. 先铺满矩形冰，再放你、箱、星、门。墙砖最后：只挡「不碰箱子也能擦到星」的那条线。  
2. **满星是一条向前的路**：星 → 星 → 门。进门是路线终点，**禁止**「吃光星星 → 原路返回起点 → 再向下进门」。转弯、推箱算前进。  
3. **一星是不吃星进门**，不是吃完再折回。进门本身可以用箱子/墙来规划；不必空手直达，也不必把门放在角落。箱子可以多只，盘面可以大于 3×4。  
4. 多出来的冰可以乱走，但不能变成满星捷径。验收：BFS 禁止 ① 和 ② 时，吃不到两颗星（`iceSim.test.ts` 的 `canThreeStarsWithoutBox`）。  
5. 满星路线中途不得回到开局格（`returnsToStartBeforeWin`）。  
6. 教学：第 1 关只教 ①；第 2 关强迫 ②。不要十五关同一张「右袋/竖井吃完再折返」。  
7. 一关一句话。说不清这关箱子在管哪一次转弯，就拆掉。  
8. **变种 ≠ 转置。** 下一关必须改停点图（出发边、闲箱、门列、星位）。同一张图转 90° / 镜像不算新关。  
9. **门的朝向用整盘旋转**（`levels.ts` 的 `orient`：人/箱/星/门/墙一起转）。不要只挪门。转完仍须满足 4–5；满星若折回起点就不要转。  
10. 相邻关的门尽量不在同一条边。验收：十五关满星方向串互不相同。

### 已否决的出题（实装翻过车）

| 否决 | 原因 |
|------|------|
| 星放在畅通行列上 | 多走一个往返就能 3 星，箱子摆设 |
| 十五关同一口竖袋，推箱到最右再下井折返 | 玩法相同，没有路径管理 |
| 同一张图转 90° / 镜像当新关 | 停点图没变，玩家一眼认出来 |
| 只挪门、不改箱子停点 | 解法散掉，或仍是同一条漏斗 |
| 用墙填满矩形 / 挖空当墙 | 多余格应是冰 |
| 第 1 关零墙且星在飞过路径上 | 墙该加在挡捷径处；不是永远零墙 |

## 8. 十五关怎么排

母本五种：①撞停、②贴推、推到再推、枢纽钉、先停后推。第 4、6 关是枢纽母本（钉反复当车站；用完再搬走）。其余关是变种：换出发、加闲箱、偏心、门列偏移——**不是转置克隆**。

门的边用 `orient` 整盘转：底 / 左 / 顶 / 右错开。第 12 关转了会折回起点，保持底边。

明细、朝向表、一句话：[LEVEL-TEMPLATES.md](./LEVEL-TEMPLATES.md)。
